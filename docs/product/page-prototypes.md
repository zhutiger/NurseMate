# 关键页面与交互原型

> 可点击演示：[打开原型](../prototype/index.html)

## 1. 原型目标

原型用于确认页面信息结构、核心操作路径、状态反馈和角色差异。视觉细节可在 UI 设计阶段优化，但页面编号、必需信息和关键操作需保持一致。

## 2. 全局导航

### 2.1 护士端

底部导航固定为：

1. 首页
2. 消息
3. 任务
4. 我的

### 2.2 管理端

移动端管理入口从护士长或协管员首页进入；电脑管理端使用 `/admin/` 独立入口，两端复用相同权限和业务接口。电脑端使用左侧导航和宽表格，适合批量发布、审核、导出和人员维护。管理页面包含：

1. 管理首页
2. 发布中心
3. 通知管理
4. 任务管理
5. 人员管理
6. 审计日志

用户始终保留返回本人首页的入口。

## 4. 页面规格

### AUTH-P01 账号首次激活

必需字段：

- 科室工号。
- 一次性激活码。
- 小程序与 H5 共用的登录密码及确认密码。
- 用户协议与隐私说明确认。

交互规则：

- 点击提交后禁用按钮，防止重复请求。
- 激活成功后可在当前端直接登录；小程序同步尝试关联微信身份。
- 微信身份关联失败不影响账号密码登录。
- 错误提示不透露其他人员账号信息。
- 激活码过期时提示联系护士长重新生成。

### NURSE-P01 首页

信息顺序：

1. 当前用户问候和角色。
2. 待确认消息与待完成任务数字卡片。
3. 紧急、逾期和临近截止事项。
4. 最近更新事项。

首页不展示排名、积分、确认速度和无操作价值的统计。

### NURSE-P03 通知详情

必须展示：

- 通知等级、标题、当前版本和发布时间。
- 发布人、确认期限、本人当前状态。
- 正文和附件。
- 版本更新说明。
- “我已阅读并知晓”按钮或确认结果。

确认按钮在正文区域展示完成后可用。确认后显示服务端确认时间，不提供取消入口。

### NURSE-P05 任务详情

简单完成模式显示“标记已完成”。审核完成模式显示文字反馈、附件和“提交反馈”。退回状态优先展示审核意见及重新提交入口。

提交前显示本次内容摘要。提交成功后页面切换为已提交状态，并展示服务端提交时间。

### ADMIN-P02 发布中心

字段顺序：

1. 内容类型：阅读确认通知或工作任务。
2. 标题与正文。
3. 重要等级。
4. 完成模式，仅任务显示。
5. 截止时间。
6. 附件。
7. 接收范围与人员。
8. 规则预览。

页面底部提供“保存草稿”和“下一步预览”。不得从编辑页直接正式发布。

移动端发布表单中的等级和完成方式应显示中文选项，选择控件应有明确的下拉标识，并在选中后说明该规则的含义。发布前二次确认须显示实际接收人数。

任务发布的截止时间可选年月日、小时和分钟；任务附件支持图片、PDF、Word 文档，列表可移除已选文件，发布后负责人在详情中下载。附件单个不超过 10 MB、最多 9 个，不录入患者敏感资料。

通知管理列表提供五种业务状态（草稿、已发布、已关闭、已撤回、已取消）和三级重要程度筛选；“全部”表示不加该维度过滤。人员管理展示账号状态、停用时间和停用原因，并提供编辑人员、协管员授权、重置密码、重新启用及分组编辑。

### ADMIN-P05 通知确认明细

顶部展示有效接收人数、已查看、已确认、未确认和逾期人数。人员列表支持按状态筛选，展示姓名、状态、查看时间、确认时间和最近提醒结果。

批量催办只作用于当前筛选结果中的有效未确认人员，操作前显示影响人数。

### ADMIN-P08 任务审核

必须展示任务要求、本次提交、附件、提交时间和历史退回记录。“审核通过”和“退回补充”是两个独立动作，退回时审核意见必填。

## 5. 全局交互状态

每个包含数据的页面必须设计以下状态：

- 首次加载。
- 正常内容。
- 空数据。
- 加载失败及重试。
- 无权限。
- 业务状态已变化，需要刷新。
- 提交中、提交成功和提交失败。

列表分页加载失败不得清空已经加载的数据。

## 6. 表单与反馈

- 必填字段在提交前明确标识。
- 错误提示靠近对应字段，并在页面顶部提供摘要。
- 截止时间同时显示完整日期时间和相对剩余时间。
- 发布、撤回、关闭、批量催办、审核退回和停用账号需要二次确认。
- 成功提示包含业务结果，例如“已向 4 名未确认人员发起催办”。
- 网络超时后不得直接假设失败，应查询服务端最终状态。

## 7. 视觉基线

| 品牌深青蓝 | `#005870` |

| 品牌薄荷绿 | `#88C8B8` |

| 紧急与错误 | `#C84E4E` |
| 主文字 | `#153941` |
| 次级文字 | `#5D7479` |
| 页面背景 | `#EFF5F6` |

品牌色取自广东药科大学附属医院院徽。深青蓝用于导航、标题和管理端重点区域，主青蓝用于主要操作，薄荷绿用于辅助图形与柔和状态背景。状态必须同时使用文字表达，不依赖颜色作为唯一识别方式。
