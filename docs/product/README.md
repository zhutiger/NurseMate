# 产品基线文档

本目录保存 V1.0 开发的产品执行基线。

| 文档 | 内容 |
| --- | --- |
| `v1-scope.md` | 功能范围、需求编号和边界 |
| `auth-binding.md` | 登录、激活、绑定、重置和停用流程 |
| `permission-matrix.md` | 角色、权限代码和数据范围 |
| `state-machines.md` | 账号、通知、任务和提醒状态流转 |
| `page-prototypes.md` | 页面编号、信息结构和交互规则 |
| `acceptance.md` | V1.0 验收场景和完成标准 |

以上文档发生冲突时，先停止相关实现并修正文档。产品范围以 `v1-scope.md` 为准，权限以 `permission-matrix.md` 为准，状态流转以 `state-machines.md` 为准。
