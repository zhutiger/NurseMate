# 角色与权限矩阵

> 适用需求：USER-04～USER-06、REPORT-03～REPORT-04

## 1. 角色

| 角色代码 | 名称 | 权限方式 |
| --- | --- | --- |
| `HEAD_NURSE` | 护士长 | 拥有本科室全部 V1.0 管理权限 |
| `COORDINATOR` | 协管员 | 基础护士权限加护士长逐项授予的管理权限 |
| `NURSE` | 普通护士 | 仅处理本人通知、任务和个人记录 |

## 2. 权限代码

| 权限代码 | 能力 |
| --- | --- |
| `notice.publish` | 创建、编辑和发布通知 |
| `notice.stats` | 查看全科通知确认统计和人员明细 |
| `notice.remind` | 对未确认人员发起催办 |
| `notice.manage` | 版本更新、排除接收人、关闭和撤回通知 |
| `task.publish` | 创建、编辑和发布任务 |
| `task.stats` | 查看全科任务执行统计和人员明细 |
| `task.remind` | 对未完成人员发起催办 |
| `task.review` | 审核通过或退回任务提交 |
| `task.manage` | 关闭、撤回和调整任务负责人 |
| `user.manage` | 管理人员、分组、账号状态和绑定重置 |
| `permission.manage` | 设置协管员权限 |
| `report.export` | 导出通知和任务管理记录 |
| `audit.view` | 查看本科室审计日志 |

## 4. 数据范围

| 数据对象 | 护士长 | 协管员 | 普通护士 |
| --- | --- | --- | --- |
| 人员基础信息 | 本科室全部 | 仅发布选择所需的有效人员摘要 | 本人 |
| 通知正文 | 本科室全部 | 本人接收或其有权管理的通知 | 本人接收 |
| 通知确认明细 | 本科室全部 | 具有 `notice.stats` 时查看其有权管理的通知 | 仅本人记录 |
| 任务正文 | 本科室全部 | 本人负责或其有权管理的任务 | 本人负责 |
| 任务提交附件 | 本科室全部 | 具有 `task.review` 或 `task.stats` 时查看相关任务 | 仅本人提交 |
| 提醒记录 | 本科室全部 | 具有对应催办或统计权限时查看 | 仅本人收到的提醒摘要 |
| 审计日志 | 本科室全部 | 具有 `audit.view` 时查看 | 不可查看 |

## 5. 授权规则

- 协管员默认只有普通护士权限，管理权限由护士长逐项授予。
- `notice.publish` 不自动包含 `notice.stats`、`notice.remind` 或 `notice.manage`。
- `task.publish` 不自动包含 `task.review`、`task.stats` 或 `task.manage`。
- 人员管理、权限管理和账号重置只属于护士长。
- 至少保留一名 `ACTIVE` 状态的护士长，系统拒绝停用或降级最后一名护士长。
- 权限变更立即生效，并撤销旧会话中的权限缓存。
- 所有管理接口同时校验权限代码、科室归属和目标数据范围。

## 6. 服务端校验顺序

```text
验证访问令牌
→ 检查账号状态
→ 检查科室归属
→ 检查角色或权限代码
→ 检查目标数据范围
→ 检查业务状态是否允许操作
→ 执行业务事务并写入审计日志
```
