# 护知音管理员使用说明

## 人员与权限

- 护士长预建账号后，将工号和一次性激活码安全转交本人。
- 离科人员使用“停用”处理，必须填写原因；停用立即使旧会话失效，但保留历史记录。
- 系统至少保留一名有效护士长。
- 协管员按职责分别授予发布、统计、催办、审核、导出等权限，不默认继承其他管理能力。

## 发布通知

1. 填写标题、正文、等级、确认期限和附件。
2. 选择全员、护理分组或指定人员，核对去重后的实际人数。
3. 二次确认后发布，系统固定接收人快照并生成审计记录。
4. 管理明细分别显示未查看、已查看、已确认和逾期派生状态。
5. 内容修订生成新版本；默认要求重新确认，旧版本和确认记录保持可查。

## 发布和审核任务

- 创建时必须确定“简单完成”或“审核完成”，发布后不能直接切换模式。
- 审核任务退回必须填写意见，护士重提后形成新的提交版本。
- 两名管理员并发审核时只有一个请求能够改变状态，另一请求返回状态冲突。
- 管理端可以追加或排除误选负责人，排除必须填写原因并保留历史。

## 催办与自动提醒

- 站内提醒是基础渠道，微信订阅消息是辅助渠道，发送成功不代表已经阅读。
- 自动提醒由 BullMQ 生成截止前和逾期任务；完成、确认、排除、关闭或撤回后不再产生无效提醒。
- 同一事项、对象和渠道的人工催办间隔至少 10 分钟，每日最多 3 次。
- 微信模板未配置、用户未关联微信或发送失败时会保留明确的渠道结果，不影响核心业务状态。

## 导出和审计

- 通知确认和任务处理明细可导出 CSV，下载地址 24 小时有效。
- 导出、发布、确认、提交、审核、催办及账号管理均记录操作人、时间、对象和结果。
- 审计查询仅提供读取，不提供修改或删除入口。
