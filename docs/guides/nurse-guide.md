# 护知音护士端使用说明

## 登录与激活

1. 首次使用时选择“首次激活”，输入护士长提供的工号和一次性激活码。
2. 设置至少 10 位且同时包含字母、数字的密码。
3. 后续在 H5 或小程序使用同一工号、密码登录，两个端对应同一个内部账号。
4. 激活码、密码或账号停用问题由护士长处理，不要把账号交给他人使用。

## 通知确认

- 首页和“消息”展示本人收到的有效通知。
- 打开正文后系统记录首次查看时间，此时才能点击“我已阅读并知晓”。
- 确认仅表示已经阅读，不表示某项工作已经完成。
- 通知重要内容发生修改并要求重新确认时，会重新进入待确认列表；旧版本记录仍然保留。
- “逾期”仅表示需要跟进，不由系统自动判定为违规。

## 任务处理

- 简单完成任务：完成要求后点击“标记已完成”。
- 审核完成任务：填写反馈并按要求上传附件，再提交管理员审核。
- 被退回时可查看审核意见并重新提交；每次提交形成独立版本，原记录不会被覆盖。
- 已提交待审核不计为护士未完成；只有待完成或退回补充状态可能派生为逾期。

## 附件与信息安全

- 支持 PDF、DOCX、JPEG、PNG、WebP，单文件不超过 10MB。
- 不得上传患者病历、身份证、具体病情、诊疗影像或其他超出科室工作通知范围的资料。
- 文件上传后由服务端核对大小和 SHA-256，只有核验通过的附件才能关联业务记录。

## 紧急事项

涉及患者安全的紧急事项不能只依赖小程序。仍须执行电话、交接班或医院规定的其他可靠通知方式。
